## Template Usage Guide

### When to Create a Proposal
Create a proposal document when:
- Adding a **new major system** (like GameState, Combat, Save/Load)
- Making **significant architectural changes**
- Implementing **complex features** that affect multiple systems
- Planning features that require **cross-system integration**

### Sections You Can Omit
Depending on feature complexity, you can skip:
- **Section 8 (Risks)** - For low-risk features
- **Section 11 (Testing Strategy)** - For simple features with obvious testing
- **Section 12 (Performance)** - For features with negligible performance impact
- **Multiple diagrams** - One good diagram may be enough

### Sections You Should Always Include
- **Section 1 (Overview)** - Always define the problem and solution
- **Section 2 (Architecture)** - Always show the high-level design
- **Section 3 (Implementation)** - Always provide code structure
- **Section 7 (Checklist)** - Always break down implementation steps
- **Section 13 (Summary)** - Always provide quick reference

### Mermaid Diagram Tips
- Use **graph TB** for system overviews (top-bottom flow)
- Use **sequenceDiagram** for data flow and interactions
- Use **classDiagram** for class relationships
- Use **stateDiagram-v2** for state machines
- Remember to escape special characters as noted in project instructions

### Best Practices
1. **Start with the problem** - Make sure the "why" is clear
2. **Keep diagrams simple** - One concept per diagram
3. **Provide code examples** - Show actual usage patterns
4. **Think about integration** - How does this fit into existing systems?
5. **Plan for testing** - How will you verify it works?
6. **Update status regularly** - Keep the status field current as work progresses

### Example Status Progression
```
⏳ Proposal → ✅ Approved → 🔧 In Progress → ✅ Implemented
```

### Priority Levels Guide
- **LOW**: Nice to have, can be postponed
- **MEDIUM**: Important for future development
- **HIGH**: Critical for current sprint/milestone
- **CRITICAL**: Blocking other development work
